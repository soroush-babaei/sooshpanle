# SooshPanel — پنل مدیریت کانفیگ مقاوم در برابر فیلترینگ

> ⚠️ **سلب مسئولیت:** این پروژه فقط برای استفاده **شخصی/تحقیقاتی** طراحی شده است. فروش خدمات، استفاده تجاری یا نقض قوانین محلی بر عهده کاربر است. از کدهای مخرب، حمله به سروران دیگران یا دور زدن امنیت افراد دیگر پرهیز شود.

---

## ۱. معماری پیشنهادی (نمودار متنی)

```
کاربر (موبایل/PC)
      │  VLESS+WS+TLS  /  VLESS+Reality
      ▼
Cloudflare CDN  (لایه دفاعی مقابل DPI — پورت 443 استاندارد)
      │
      ▼
Cloudflare Tunnel (cloudflared)  ── بدون باز بودن IP واقعی سرور
      │  WebSocket
      ▼
┌─────────────────── VPS ارزان (Ubuntu 22.04 + Docker) ───────────────────┐
│  ┌────────────────┐      ┌─────────────────────┐   ┌─────────────────┐  │
│  │  SooshPanel    │◄────►│      Xray-core      │◄──│ Stats sidecar   │  │
│  │ (FastAPI + UI) │ مولد │ VLESS-WS + Reality  │   │ (خواندن آمار    │  │
│  │ SQLite + TOTP  │ کانفیگ│ گریسکین پورت‌های    │   │ مصرف هر کاربر)  │  │
│  └────────────────┘      └─────────────────────┘   └─────────────────┘  │
│  nginx (اختیاری: TLS مستقیم برای Reality)      ولووم: db/ + xray-config │
└─────────────────────────────────────────────────────────────────────────┘
```

**جریان مدیریت:** ادمین → پنل وب (JWT + TOTP) → API بک‌اند → تولید `config.json` برای Xray → ری‌لود هسته → کاربر لینک اشتراک `/sub/{token}` می‌گیرد (پشتیبانی از v2rayNG، Streisand، Nekoray و…).

## ۲. انتخاب استک فناوری و دلیل

| لایه        | انتخاب                                  | دلیل                                                                                                               |
| ----------- | --------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| هسته پروکسی | **Xray-core**                           | تنها هسته با پشتیبانی کامل Reality، XTLS-Vision، gRPC و WebSocket؛ به‌روزترین پروژه با استاندارد `sing-box`-سازگار |
| CDN         | **Cloudflare (Free)**                   | پوشش کامل روی همه اپراتورهای ایران، پورت‌های 443/8443/2053 و… روی WS؛ IP واقعی مخفی می‌ماند                        |
| تونل        | **Cloudflare Tunnel**                   | بدون نیاز به IP تمیز؛ در صورت فیلتر شدن IP، تونل بدون تغییر دامین جابه‌جا می‌شود                                   |
| بک‌اند      | **Python 3.12 + FastAPI**               | سرعت توسعه بالا، تایپ‌هینت، OpenAPI خودکار، async — مناسب پنل با چند صد کاربر                                      |
| دیتابیس     | **SQLite (WAL)**                        | تک‌سرور، بدون وابستگی؛ پشتیبان‌گیری = کپی یک فایل. برای +۵۰۰۰ کاربر به PostgreSQL مهاجرت کنید                      |
| فرانت‌اند   | HTML/JS خالص (بدون build)               | بدون CDN خارجی (تحریم/فیلترینگ)، تک‌فایل، سریع                                                                     |
| احراز هویت  | JWT کوتاه‌مدت + TOTP (2FA) + لاگ دسترسی | استاندارد صنعتی، بدون سرویس خارجی                                                                                  |
| QR          | تولید سمت سرور (کتابخانه `qrcode`)      | بدون وابستگی به CDN جاوااسکریپت                                                                                    |

### مقایسه گزینه‌های استقرار

| گزینه                                             | مزیت                                                                   | عذر                                                                   |
| ------------------------------------------------- | ---------------------------------------------------------------------- | --------------------------------------------------------------------- |
| **VPS ارزان + Docker (انتخاب‌شده)**               | کنترل کامل، پورت‌های دلخواه برای Reality (تک‌TCP)، هزینه ~۳–۵ دلار/ماه | نیاز به نگهداری                                                       |
| Cloudflare Workers/Pages تنها                     | رایگان، ضدسانسور لایه لینک اشتراک                                      | **نمی‌تواند هسته Xray را اجرا کند**؛ فقط مناسب لینک اشتراک/edgetunnel |
| سرور ابری ایرانی                                  | پینگ عالی                                                              | IP ایرانی فیلترپذیر و ریسک قانونی بالاتر؛ **توصیه نمی‌شود**           |
| Cloudflare Workers + Durable Objects (edgetunnel) | بدون سرور                                                              | محدود به پروتکل‌های WebSocket وابسته به CF، کارایی پایین‌تر           |

**نتیجه:** هسته روی VPS خارج + Cloudflare (CDN/Tunnel) برای عبور از فیلترینگ. Workers را فقط به‌عنوان آینه‌ی لینک اشتراک (اختیاری) استفاده کنید.

## ۴. راه‌اندازی قدم‌به‌قدم

### پیش‌نیازها

- VPS خارج (۱ گیگ رم، اوبونتو ۲۲.۰۴) با IP تمیز
- یک دامنه روی Cloudflare (رکورد A → IP سرور، Proxy روشن)

### مراحل

1. **کلون و تنظیمات**

   ```bash
   git clone <repo> /opt/sooshpanel && cd /opt/sooshpanel
   cp .env.example .env
   # SECRET_KEY، پسورد ادمین، دامنه، UUIDها را در .env تنظیم کنید
   ```

2. **اجرای استک**

   ```bash
   docker compose up -d --build
   ```

   پنل روی `http://SERVER_IP:8000` بالا می‌آید (بعداً با ابر CF مخفی کنید).

3. **Cloudflare Tunnel (پیشنهادی)**

   ```bash
   docker run -d --name tunnel --restart unless-stopped --network soosh-net \
     cloudflare/cloudflared:latest tunnel --no-autoupdate run \
     --token <TOKEN_از_داشبورد_CF>
   ```

   در CF، مسیر `panel.example.com` → `http://sooshpanel:8000` و `xray.example.com` → `http://xray:8080` (برای WS).

4. **وارد پنل شوید**؛ با نام کاربری/پسورد `.env` + کد TOTP از Google Authenticator (QR 2FA در اولین ورود نمایش داده می‌شود).

> **نکته ری‌لود هسته:** Xray کانفیگ را هات‌ریلود نمی‌کند. پنل پس از هر تغییر، `config.json` را بازنویسی و از طریق سوکت Docker (`/var/run/docker.sock` که در compose مانت شده) کانتینر `soosh-xray` را ری‌استارت می‌کند. اگر سوکت Docker را به‌دلایل امنیتی حذف کردید، پس از هر تغییر کاربر دستی `docker restart soosh-xray` بزنید.

5. **ایجاد کاربر** → لینک اشتراک و QR تولید می‌شود. کانفیگ Xray خودکار بازسازی و هسته ری‌لود می‌شود.

### بهینه‌سازی/امنیت سرور (UFW)

```bash
ufw default deny incoming && ufw default allow outgoing
ufw allow 22 && ufw allow 8000    # یا فقط از طریق تونل
ufw enable
```

- **Rate limit:** nginx/CF rate limit روی مسیر `/sub/` و لاگین.
- **به‌روزرسانی خودکار:** `unattended-upgrades` روی VPS؛ ایمیج‌ها را ماهانه `pull` کنید.
- **پشتیبان‌گیری:** کرانی که `data/soosh.db` را رمزگذاری‌شده به مخزن دور/BACKBLAZE می‌فرستد.

## ۶. چک‌لیست تست در شرایط فیلترینگ

- [ ] تست روی همراه اول، ایرانسل، رایتل، مخابرات، شاتل (هم 4G هم FTTH)
- [ ] تست VLESS+WS+TLS از طریق CDN (باید روی همه اپراتورها بگذرد)
- [ ] تست VLESS+Reality (XTLS-Vision) روی IP تمیز
- [ ] تست لینک اشتراک در v2rayNG / Streisand / Hiddify
- [ ] قطع/وصل اینترنت → اتصال خودکار برقرار شود
- [ ] زمان اتصال زیر ۵ ثانیه (warm-up)
- [ ] محدودیت حجم/انقضا: پس از اتمام، اتصال کاربر واقعاً قطع شود (تست با کاربر آزمایشی)
- [ ] آمار مصرف در پنل با آمار گوشی هم‌خوان باشد
- [ ] 2FA: ورود بدون کد TOTP باید ناموفق باشد
- [ ] پشتیبان DB یک‌بار به‌صورت دستی بازیابی و تست شود

## ۸. استقرار سریع + نقشه سرعت (Cloudflare)

### نصب خودکار (پیشنهادی)

```bash
# روی VPS اوبونتو:
bash scripts/install-vps.sh
```

این اسکریپت Docker را نصب، SECRET_KEY/پسورد ادمین و کلیدهای Reality (x25519) را تولید، فایروال را می‌بندد و کل استک را بالا می‌آورد؛ در انتها فقط توکن تونل CF را می‌پرسد.

### آینه اشتراک روی Workers (رایگان، همیشه‌در‌دسترس)

فایل `worker/sub-worker.js` را در Cloudflare Workers دیپلوی کنید و متغیر `SUB_URL` را روی آدرس پنل بگذارید؛ سپس لینک اشتراک کاربران را از دامنه Worker بدهید تا حتی با اختلال در دامنه اصلی هم subscription باز شود.

### نقشه سرعت — کدام کانفیگ را به کاربر بدهید؟

| مسیر                                     | سرعت واقعی روی اپراتورهای ایران              | توصیه                          |
| ---------------------------------------- | -------------------------------------------- | ------------------------------ |
| **Reality + Vision (پورت 8443، مستقیم)** | ⭐⭐⭐⭐ بالاترین — بدون واسطه، XTLS روی TCP | **اصلی**؛ فقط IP تمیز می‌خواهد |
| VLESS+WS+TLS از CDN                      | ⭐⭐ حدود ۲۰–۶۰ مگابیت (وابسته به اپراتور)   | **پشتیبان**؛ وقتی IP فیلتر شد  |
| Workers برای اشتراک                      | —                                            | فقط لینک، نه تونل ترافیک       |

نکات سرعت:

- بعد از ساخت کانفیگ، در کلاینت `mux` را **خاموش** نگه دارید (سرعت را می‌کُشد).
- برای Reality در کلاینت فینگرپرینت `chrome` و `flow=xtls-rprx-vision` را دقیقاً نگه دارید.
- اگر IP سرور فیلتر شد: کاربران را روی WS/CDN نگه دارید و IP جدید بخرید؛ تونل CF بدون تغییر دامنه می‌ماند.
- انتخاب لوکیشن VPS: ترکیه/امارات/اروپای شرقی بهترین پینگ به ایران.

## ۹. کانفیگ‌های کلیدی Xray (خلاصه)

پنل به‌صورت خودکار `xray/config.json` را می‌سازد؛ دو اینباند فعال است:

1. **VLESS + WebSocket** (پورت داخلی 8080، پشت Cloudflare) — مقاوم‌ترین گزینه روی اپراتورهای سخت‌گیر
2. **VLESS + Reality (Vision)** (پورت 8443، بدون CDN) — سریع‌ترین، نیازمند IP تمیز

SNI، فینگرپرینت (uTLS = `chrome`)، مسیر WS و UUID هر کاربر از پنل قابل تغییر است.
